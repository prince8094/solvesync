SolveSync

Solve once. Track everywhere.

⚠ One-time developer setup needed

This copy of SolveSync doesn’t have a Google OAuth client ID yet, so Google sign-in can’t start. Follow docs/GOOGLE_SETUP.md (about 10 minutes), paste the client ID into manifest.json, then reload the extension. People who install the finished extension never see this.

⚠ One-time developer setup needed for this browser

Brave, Edge, Opera and Vivaldi don’t have Chrome’s built-in Google sign-in, so SolveSync uses a second sign-in method that needs a Web application OAuth client. Follow docs/GOOGLE_SETUP.md, section 7, paste its client ID into background/config.js (WEB_CLIENT_ID), then reload the extension. People who install the finished extension never see this.
